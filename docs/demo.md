# Demo data

SolvAI never fabricates financial data, so the demo runs on real test-mode accounts. Their keys live in `.env.demo` at the repo root. The file is git-ignored; ask the maintainer for it.

```bash
# .env.demo
STRIPE_DEMO_TEST_KEY=sk_test_...
PAYPAL_SANDBOX_CLIENT_ID=...
PAYPAL_SANDBOX_SECRET=...
```

## Stripe (12 months of history)

The Stripe test account behind `STRIPE_DEMO_TEST_KEY` ("SolvAIDEMO2", seeded 2026-10-26) holds 12 complete months plus the current one, generated by `backend/scripts/seed_stripe.py`. The profile is about €6,900/month, 10 clients, top client about 26%, income CoV about 19%, a gentle +1.2%/month growth and a quieter August.

Stripe cannot create charges in the past, so each seeded charge stores its date in `metadata.historical_created`. The app honours that field **only for test-mode keys**; in live mode it would let anyone backdate charges.

```bash
cd backend
set -a; . ../.env.demo; set +a
python scripts/seed_stripe.py --dry-run      # plan only
python scripts/seed_stripe.py --top-up       # add the days since the last seeded charge (e.g. before the demo)
```

The script refuses to seed an account that already has charges: layering seed runs is what ruined the previous demo account. To start over, create a fresh test account.

## PayPal sandbox (built up daily)

PayPal's sandbox cannot backdate transactions, so history is built by creating a few real sandbox payments every day:

```bash
cd backend
set -a; . ../.env.demo; set +a
python scripts/seed_paypal_sandbox.py --count 3     # --dry-run only checks credentials
```

Payments are card payments captured through Orders v2 from six weighted fictional clients. They show up in Transaction Search after a delay of up to a few hours.

Sandbox app requirements (developer.paypal.com → Apps & Credentials):

- The app is linked to a **Spain/EUR business** sandbox account.
- **Transaction search** is enabled under Features. After enabling it, the old cached token must expire or be revoked (`POST /v1/oauth2/token/terminate`) before new tokens carry the `reporting/search/read` scope.

### Running it every day automatically (macOS)

`backend/scripts/daily_paypal_seed.sh` creates 2–4 payments per run. To schedule it daily at 10:30 with launchd (if the Mac is asleep then, it runs on wake), save this as `~/Library/LaunchAgents/com.solvai.paypal-seed.plist`, adjusting the paths:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>com.solvai.paypal-seed</string>
  <key>ProgramArguments</key>
  <array><string>/Users/YOU/SolvAI/SolvAI/backend/scripts/daily_paypal_seed.sh</string></array>
  <key>StartCalendarInterval</key>
  <dict><key>Hour</key><integer>10</integer><key>Minute</key><integer>30</integer></dict>
  <key>StandardOutPath</key><string>/Users/YOU/SolvAI/SolvAI/logs/paypal-seed.log</string>
  <key>StandardErrorPath</key><string>/Users/YOU/SolvAI/SolvAI/logs/paypal-seed.log</string>
</dict>
</plist>
```

```bash
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.solvai.paypal-seed.plist   # enable
launchctl bootout gui/$(id -u)/com.solvai.paypal-seed                                 # disable after the hackathon
```

## Demo flow

1. Register a fresh account.
2. Go to **Data Sources** and click **Try with demo data**. It connects the Stripe test account and the PayPal sandbox with credentials kept on the server, and labels both sources "Demo data". The button only shows when the server has `DEMO_STRIPE_TEST_KEY` (a `sk_test_` key) and, optionally, `DEMO_PAYPAL_CLIENT_ID` / `DEMO_PAYPAL_SECRET`. You can also connect **Stripe** and **PayPal** by hand with the same keys.
3. On the **Dashboard**, click **Generate New Report** and watch the Intelligence Terminal stream the pipeline steps.
4. Open the report: the score, explainable factors, risk flags and data references, each traceable to transactions.
5. Download the PDF (Pro/Business, or unlock per report) and scan the QR code to verify it. A fresh account gets Pro with the judges' promo code, at sign-up or under **Account** (see [deploy-vm.md](deploy-vm.md)).
